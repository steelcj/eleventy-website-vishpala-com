Le pouvoir d’agir, c’est garder le contrôle. Pour les visiteurs, cela veut dire une conception honnête, sans astuces qui les poussent vers des choix qu’ils n’avaient pas l’intention de faire. Pour votre organisation, cela veut dire que votre contenu vous appartient et que vous pouvez changer de plateforme sans repartir de zéro. Notre guide <a href="/en/services/resources/guides/choosing-a-website-platform/" hreflang="en">Questions to ask before choosing a website platform</a> (en anglais) traite du volet organisationnel.
